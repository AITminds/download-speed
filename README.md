# Download Speed

Консольный скрипт на Python, который скачивает содержимое URL **10 раз последовательно**,
измеряет среднее время запроса, общий объём данных и скорость скачивания.

## Требования

- Python **3.10 или новее**.
- Только стандартная библиотека: установка пакетов через `pip` не нужна.

## Запуск

Откройте терминал в папке проекта и передайте ссылку на файл:

```bash
python download_speed.py "https://example.com/image.jpg"
```

Замените пример на существующую прямую ссылку на файл. URL нужно заключать в кавычки,
особенно если в нём есть `&`. На Linux/macOS команда Python может называться `python3`,
на Windows также можно использовать `py`.

Таймаут сетевой операции по умолчанию — 30 секунд. Его можно изменить:

```bash
python download_speed.py "https://example.com/image.jpg" --timeout 60
python download_speed.py --help
```

`--timeout` ограничивает ожидание блокирующих операций с сокетом, например подключения
или чтения данных. Это **не ограничение общей длительности** скачивания: пока сервер
продолжает передавать данные, весь запрос может занимать больше указанного времени.

Скрипт выводит результат каждого запроса, затем итог. Ниже **условный пример итоговых
значений**, а не результат реального измерения:

```text
Requests: 10
Average request time: 0.500 s
Total downloaded: 10000000 bytes (10.000 MB)
Total request time: 5.000 s
Download speed: 2.000 MB/s
```

## Расчёты и единицы измерения

- Время измеряется в **секундах** высокоточным монотонным таймером `time.perf_counter()`.
- Объём — фактическое количество **байтов тела ответа**, прочитанных за все 10 запросов.
- Скорость — **MB/s (мегабайты в секунду)**, где `1 MB = 1 000 000 байтов`.
- MB/s отличается от мегабит в секунду: для перевода в Mbit/s нужно умножить на 8.

```text
Среднее время запроса = сумма времени всех запросов / 10
Общий объём = сумма прочитанных байтов всех ответов
Скорость, MB/s = общий объём / сумма времени всех запросов / 1 000 000
```

Для скорости используется отношение общего объёма к общему времени,
а не среднее арифметическое скоростей отдельных запросов.

## Как работает замер

1. Проверяет URL (`http://` или `https://`) и положительный конечный таймаут.
2. Начинает замер перед отправкой GET-запроса.
3. Читает **всё тело ответа** блоками по 64 KiB. Файл не сохраняется на диск
   и не загружается целиком в память.
4. Завершает замер после чтения ответа и закрытия соединения.
5. Переходит к следующему запросу. Параллельных запросов и повторов при ошибке нет.
6. После 10 успешных скачиваний выводит итоговые показатели.

Время включает установление соединения, ожидание сервера и чтение тела ответа.
Вывод прогресса между запросами в него не входит. `urllib` не переиспользует соединение
между скачиваниями. Обычные HTTP-перенаправления обрабатываются автоматически:
измеряется вся цепочка, а байты считаются для конечного ответа. При перенаправлениях
10 скачиваний могут потребовать больше 10 HTTP-запросов.

Скрипт запрашивает ответ без сжатия (`Accept-Encoding: identity`) и просит перепроверять
кэш (`Cache-Control: no-cache`). Сервер может игнорировать эти заголовки; локального
кэша в скрипте нет. Если сервер всё же отправит сжатое тело, считаются полученные
сжатые байты без распаковки. HTTP-заголовки, служебные данные chunked-передачи
и накладные расходы TLS/TCP в объём не входят.

Результат описывает скачивание с конкретного сервера и зависит от его скорости,
размера файла, задержек и состояния сети. Для небольшого файла заметную долю времени
может занимать установка соединения. Один и тот же файл будет скачан 10 раз.

## Ошибки

При сетевой ошибке, HTTP-ошибке или таймауте скрипт пишет причину и номер запроса
в `stderr`, возвращает код `1` и не печатает итоговую скорость по неполной серии.
Неверные аргументы дают код `2`, прерывание скачивания через `Ctrl+C` — код `130`.
Успешное выполнение возвращает `0`.

`Content-Length` используется только для проверки полноты ответа, а объём всегда
считается по прочитанным байтам. Если сервер закрыл соединение раньше заявленной
длины, замер завершается ошибкой. Ответы без `Content-Length` и с chunked-передачей
также поддерживаются. Без заявленной длины или другого признака завершения тела
отличить штатное закрытие соединения от преждевременного средствами HTTP невозможно.

## Проверки

```bash
python -m unittest discover -s tests -v
```

Тесты используют встроенный локальный HTTP-сервер, поэтому доступ к интернету не нужен.
Проверяются полное чтение тела, последовательность 10 запросов, подсчёт байтов,
перенаправления, ответы без `Content-Length`, chunked-передача, обрыв ответа,
HTTP-ошибки, таймаут, аргументы CLI и формула общей скорости.
